# TwinPanel 1.1.26-rc.1 — Release preparation

## Included
- Fix Sudoku shared-native accounting support detection for authenticated snapshots with an empty counter map. Empty counters are treated as a valid zero-usage baseline; no bytes are fabricated.
- Add the Sudoku accounting module to the runtime integrity manifest.
- Preserve existing usage accounting semantics and per-user identity validation.

## Validation
- Python syntax compilation passed for the Sudoku accounting module.
- Regression check for an authenticated idle snapshot passed.
- Runtime observation on the production panel showed the Sudoku presence collector reporting `usage_supported=true` across its configured nodes. This is not a proof of positive byte-delta accounting; that still requires a connected test subscription and a controlled traffic delta.

## Release gate — not yet publishable
- Build the official x86_64 prebuilt artifact from this exact source commit.
- Run the full backend regression suite and release smoke tests.
- Verify the artifact SHA-256 and size.
- Publish the GitHub release asset and update `releases/stable.json` only after artifact verification.
