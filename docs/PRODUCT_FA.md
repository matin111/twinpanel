# معرفی TwinPanel

TwinPanel یک پنل Self-Hosted برای مدیریت سرویس‌های VPN، کاربران، نمایندگان، فروش، پرداخت، تونل و زیرساخت است. معماری پنل طوری طراحی شده که Backend، Frontend، دیتابیس، Redis، Nginx، سرویس‌های systemd و ابزارهای عملیاتی روی سرور مشتری نصب شوند و تنظیمات اصلی از خود پنل قابل مدیریت باشند.

## قابلیت‌های اصلی

- مدیریت کاربران و اشتراک‌ها
- ساخت، ویرایش، تمدید، تعلیق و حذف اشتراک
- پروتکل‌های Cisco/OpenConnect، OpenVPN، WireGuard، L2TP/IPsec و V2Ray/Xray
- مدیریت نودهای ایران و خارج
- مدیریت تانل، Failover و Transportهای چندگانه
- راه‌اندازی و Repair نودها از پنل
- دامنه و SSL
- فروشگاه، پلن‌ها و پرداخت
- کارت‌به‌کارت و پرداخت‌های USDT-BEP20، TRX و BNB
- نرخ آنلاین ارزهای دیجیتال
- SMS Reader و تأیید خودکار پرداخت
- نمایندگی، کیف پول، اعتبار حجمی، قیمت‌گذاری پلن و دسترسی‌ها
- ربات تلگرام فروش و مدیریت
- پشتیبانی و اعلان‌ها
- مدیریت فایل‌های دانلود
- برندینگ قابل تغییر
- بکاپ رمزگذاری‌شده و بازیابی
- امنیت، Health و Diagnostics
- فارسی RTL و English LTR
- Dark/Light mode
- بروزرسانی نسخه با Rollback و Health Check
- Trial هفت‌روزه و License قابل ارتقا بدون نصب مجدد

## مدل نصب

هر نصب TwinPanel یک Installation مستقل است. Release نصب‌شده از کانال رسمی دریافت می‌شود و نسخه‌های آزمایشی Branchها مستقیماً روی سرور مشتری نصب نمی‌شوند.

## بروزرسانی

نسخه نصب‌شده در پایین پنل نمایش داده می‌شود. وقتی نسخه جدید مجاز باشد، ادمین اعلان دریافت می‌کند و می‌تواند از داخل پنل Update را آغاز کند. فرآیند Update باید Backup، Download Verification، Build، Restart، Health Check و Rollback خودکار داشته باشد.

## License

نصب جدید می‌تواند 7 روز Trial داشته باشد. Trial به Installation در سمت License Server متصل است و حذف فایل محلی یا نصب مجدد نباید آن را ریست کند. License پولی روی همان Installation فعال می‌شود و کاربران، نودها، تونل‌ها و دیتابیس بدون تغییر باقی می‌مانند.
