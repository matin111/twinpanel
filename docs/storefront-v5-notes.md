# Storefront V5 visual fixes

- Protocol cards use the previous-panel real client artwork where available.
- Tutorial OS selectors use recognizable Android, Apple, Windows and Linux marks.
- Telegram, Instagram and WhatsApp cards use their real brand marks.
- Light mode has explicit surfaces/text/borders for storefront cards, FAQ, tutorial, CTA, social and footer areas.
- The storefront-specific floating chat button is hidden so the global SupportChatWidget launcher/window is the same one used by `/panel`.
- Legacy asset migration now copies `public/learning/screenshots` in addition to `public/learning/apps`.
